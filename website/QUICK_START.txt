🚀 دليل البدء السريع - نظام تسجيل الدخول عبر Discord
═══════════════════════════════════════════════════════════

📋 الخطوات المطلوبة:

1️⃣ إعداد Discord Application
   ═══════════════════════════════════════════════════
   • اذهب إلى: https://discord.com/developers/applications
   • اضغط "New Application"
   • اختر اسم (مثلاً: Tournament System)
   
2️⃣ الحصول على المعلومات المطلوبة
   ═══════════════════════════════════════════════════
   في صفحة Application:
   • انسخ "APPLICATION ID" (هذا هو Client ID)
   • اذهب لتبويب "OAuth2"
   • اضغط "Reset Secret" وانسخ الـ Secret

3️⃣ إضافة Redirect URLs
   ═══════════════════════════════════════════════════
   في تبويب "OAuth2":
   • ابحث عن "Redirects"
   • أضف: http://localhost:3000/auth/callback
   • اضغط "Save Changes"

4️⃣ تحديث ملف .env
   ═══════════════════════════════════════════════════
   افتح ملف .env وأضف/عدّل:
   
   DISCORD_CLIENT_ID=الرقم_الطويل_من_الخطوة_2
   DISCORD_CLIENT_SECRET=النص_الطويل_من_الخطوة_2
   DISCORD_REDIRECT_URI=http://localhost:3000/auth/callback

5️⃣ تحديث ملف landing.js
   ═══════════════════════════════════════════════════
   افتح: public/assets/landing.js
   
   غيّر السطر:
   clientId: 'YOUR_CLIENT_ID_HERE',
   
   إلى:
   clientId: 'الرقم_من_الخطوة_2',

6️⃣ الصور (✅ موجودة بالفعل!)
   ═══════════════════════════════════════════════════
   الصور موجودة في:
   public/mg1.png ✅
   public/mg2.png ✅
   public/mg3.png ✅

7️⃣ تشغيل المشروع
   ═══════════════════════════════════════════════════
   npm run build
   npm start

8️⃣ اختبار النظام
   ═══════════════════════════════════════════════════
   • افتح: http://localhost:3000/landing.html
   • اضغط "Login" أو "Get Started"
   • يجب أن يفتح صفحة Discord
   • اضغط "Authorize"
   • يجب أن يرجعك للـ Dashboard

═══════════════════════════════════════════════════════════
✅ ملفات جديدة تم إنشاؤها:
═══════════════════════════════════════════════════════════

1. public/landing.html - الصفحة الرئيسية الجديدة
2. public/assets/landing.css - تصميم الصفحة
3. public/assets/landing.js - منطق تسجيل الدخول
4. DISCORD_OAUTH_GUIDE.md - شرح مفصل خطوة بخطوة
5. .env.example - مثال لملف البيئة

═══════════════════════════════════════════════════════════
🔧 APIs الجديدة:
═══════════════════════════════════════════════════════════

POST /api/auth/discord/callback
  - يستقبل الكود من Discord
  - ينشئ/يسجل المستخدم
  - يرجع Token للاستخدام

POST /api/auth/verify
  - يتحقق من صلاحية الـ Token
  - يرجع معلومات المستخدم

❓ مشاكل شائعة:
═══════════════════════════════════════════════════════════

❌ Invalid OAuth2 redirect_uri
   ✅ تأكد أن الرابط في Discord Developer Portal
      يطابق تماماً الرابط في الكود

❌ Invalid client
   ✅ تحقق من Client ID و Secret في .env

❌ الصور لا تظهر
   ✅ تأكد أن الصور في:
      public/mg1.png
      public/mg2.png
      public/mg3.png
   ✅ الصور موجودة بالفعل في المشروع!
