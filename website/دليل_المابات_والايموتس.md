## 🎮 كيفية الاستخدام

### اختيار المابات:
1. اضغط على بطاقة الماب → حدود خضراء تظهر
2. اضغط مرة ثانية → إلغاء التحديد
3. استخدم التبويبات للفلترة حسب النوع
4. استخدم البحث لإيجاد مابات معينة
5. العداد يوضح X / Y PICKED

### تعطيل الايموتس:
1. انتقل لتبويب EMOTES
2. اضغط على الايموت لتعطيله
3. حدود حمراء تظهر للمعطل
4. كل الايموتس الغير معطلة مسموحة
5. العداد يوضح X DISABLED
